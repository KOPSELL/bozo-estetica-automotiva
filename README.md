# Bozo Estética Automotiva

Site institucional responsivo da Bozo Estética Automotiva, em Soledade, Rio Grande do Sul.

## Publicação

O site é estático e pode ser publicado diretamente na Vercel:
1. Importe este repositório na Vercel.
2. Selecione **Other** como framework preset, se solicitado.
3. Não é necessário build command; a página inicial é `index.html`.
4. Faça o deploy.

## Antes de divulgar
- Configure o WhatsApp oficial da empresa no formulário para que os pedidos sejam enviados diretamente.
- Confirme os dias e horários reais de atendimento.
- Substitua os valores provisórios e revise os serviços.
- Confirme as imagens e informações de contato.

O formulário atual monta a mensagem de solicitação para copiar. Ele não confirma vagas nem grava agendamentos num banco de dados.
